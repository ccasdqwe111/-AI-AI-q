# AI创作小程序源码，文生图，图生图，可对接任何图像AI模型

源码获取：ym7k.com/19846/ 


随着 AI 绘图需求持续增长，很多创作者、工作室、服务商希望搭建属于自己的 AI 绘画平台，不依赖第三方 SaaS 平台的额度与版权约束。这套基于 FastAdmin + ThinkPHP + UniApp 开发的 AI 创作小程序源码，核心定位是**AI 绘图调度中台**，内置文生图、图生图两大基础能力，接口层做了抽象封装，可灵活对接 Stable Diffusion、Midjourney 代理、Flux、DALL・E、SDXL 等各类图像 AI 模型，私有化部署、可二次开发，适合打造自有品牌 AI 绘画小程序。

## 技术架构说明

后端采用 FastAdmin + ThinkPHP，利用框架自带的 RBAC 权限、任务队列、订单管理、会员体系、文件存储能力；前端 UniApp 开发，一份代码编译微信小程序、H5。
最关键的设计是**模型适配器层**，后端不绑定固定 AI 模型。所有绘图请求经过统一参数标准化之后，转发到对应的模型 API。新增模型只需要新增适配器，不用改动前端页面和业务逻辑。
任务使用消息队列异步处理绘图任务，避免长时间请求超时；绘图结果图支持本地存储、对象存储（OSS），支持图床配置。支持限流、频率控制，防止接口被恶意刷量。后台、小程序端权限隔离，管理员、普通用户、分销推广员角色分开管控。

## 核心业务功能模块

### 1. 文生图（Text to Image）

用户输入正向提示词、反向提示词，选择风格模板、尺寸、生成数量、采样器、步数、CFG 权重、种子值。
系统内置大量风格预设模板：写实、二次元、国风、油画、3D 渲染、Logo 设计、海报、插画等，新手可以直接选用模板快速生成。
提交之后进入异步任务队列，后台排队渲染，小程序端实时轮询任务状态，完成后预览、下载图片、保存历史记录。

### 2. 图生图（Image to Image）

上传参考图，支持设置重绘幅度（denoising strength），结合提示词修改原图。
常见使用场景：图片扩图、风格迁移、图片翻新、线稿上色、局部重绘（可扩展 Inpaint 局部蒙版）。用户上传图片后，系统自动转码压缩，再提交给 AI 模型接口，降低大图片传输失败概率。

### 3. 多模型自由切换，适配器化对接

这是这套源码最大亮点：**模型与业务解耦**。
后台可视化添加模型通道，填入模型 API 地址、Key、接口请求格式，选择适配器类型：

- SD / SDXL 本地 API（Automatic1111、ComfyUI）
- Flux 系列模型接口
- MJ 代理接口
- 各类国产文生图大模型服务 API
可以设置不同模型定价、权重、是否对普通用户开放。用户在前端直接下拉选择想要使用的模型，同一套界面，切换不同绘图引擎。

### 4. 用户中心、绘图历史与作品管理

自动保存全部绘图任务记录，记录提示词、参数、使用模型、生成图片。用户可以收藏作品、重新复用参数再次生成，支持一键复制提示词。
支持作品广场，开启后用户作品可公开展示、点赞收藏；也可以关闭广场，仅私有使用，适合企业内部 AI 创作工具。

### 5. 变现体系：会员、点数套餐、充值

采用点数扣费模式，每一次绘图消耗对应点数，不同模型消耗点数可以单独配置。

- 充值套餐：购买点数包；
- 会员订阅：会员每日赠送免费点数、绘图折扣、优先排队；
- 免费额度：新用户赠送免费次数，用于引流体验；
订单、充值记录、点数消耗流水全部在后台可查，支持导出对账。

### 6. 分销推广、营销模块

内置分销功能，生成专属推广海报，邀请好友注册充值，推广人获得佣金，适合社群裂变。配套优惠券、活动码，发放免费绘图次数。

### 7. 后台管理、任务监控、风控配置

后台可以查看全部绘图任务队列、任务耗时、模型接口成功率，监控各个模型通道负载，通道异常自动告警。
支持敏感词过滤，提示词违规直接拦截不提交模型；可开启人工审核作品；支持用户举报。
数据看板统计：注册量、绘图次数、各个模型调用量、充值营收，图表可视化展示。

## 部署与对接方式

两种主流部署模式任选：

1. **本地部署 SD/ComfyUI**：服务器或者显卡工作站部署 Stable Diffusion 服务，小程序后端内网 / 公网调用本地 API，没有第三方接口费用，适合自有算力的团队；
2. **调用第三方模型 API**：直接对接各类厂商开放 API，不需要自备显卡算力，轻量化快速上线。

> 
> 注意：使用第三方模型 API 需要遵守对应服务商协议；自备本地模型则需要自行处理模型权重版权、生成内容合规问题。

## 和普通绑定单一模型的 AI 绘图源码对比优势

市面上很多 AI 绘画小程序源码硬编码绑定 SD 或者只适配 MJ，换模型就要大量改代码。这套源码适配器设计，**新增图像模型只需要写少量适配脚本**，业务层完全不动，扩展性极强。小程序 + H5 双端，不用单独开发多套前端。私有化部署，提示词、用户数据、生成图片自主管理。
